# Резюме договору — ESCORE

Веб-сторінка для директора: завантажуєш скан договору (PDF або фото сторінок) → AI складає коротку таблицю: сторони, предмет, суми, ПДВ, порядок оплати, строки, гарантія, штрафи, розірвання, ключові дати і **ризики для нас**. Результат можна виправити вручну, зберегти в реєстр договорів (Google Sheets) і завантажити в PDF.

**Сайт:** https://escoreodessa.github.io/contract/

## Як працює

1. Директор перетягує скан договору (PDF або кілька фото по порядку сторінок).
2. «Розібрати договір» → таблиця заповнюється. Зелені поля — заповнені AI, їх треба звірити зі сканом (після правки поле стає жовтим).
3. «Зберегти в реєстр» → рядок додається в Google-таблицю, скан — у папку Google Drive (з посиланням у реєстрі).
4. «PDF» — резюме для друку або пересилання. «Копіювати рядок» — рядок для вставки в будь-яку таблицю вручну (Shift+клік — разом із заголовками).

Чернетка зберігається в браузері (на випадок закриття вкладки). Скани в браузері не зберігаються.

## Два режими

- **Тестовий** (`CONFIG.API_URL` порожній в `index.html`): ключ API не потрібен. «Підготувати запит» копіює інструкцію → директор відкриває claude.ai (підійде безкоштовний акаунт), **прикріплює скан**, вставляє запит → копіює відповідь назад → «Застосувати відповідь». Реєстр у цьому режимі — через «Копіювати рядок».
- **Робочий** (`CONFIG.API_URL` заповнений): вхід через Google (той самий OAuth-клієнт, що в smeta), розбір в одне натискання через Claude API, автоматичне збереження в реєстр. Ключ API лежить в Apps Script, на сайті його немає.

## Підключення робочого режиму

1. **Ключ.** console.anthropic.com → поповнити баланс → API Keys → Create key. Скопіювати ключ (показується один раз). Рекомендовано встановити місячний ліміт витрат. Можна використати той самий ключ, що для «ТЗ для замірника».
2. **Реєстр.** Створити Google-таблицю «Реєстр договорів». ID — частина адреси між `/d/` і `/edit`. Заголовки скрипт створить сам. Поділитися таблицею з директором (перегляд або редагування).
3. **Папка для сканів** (необов'язково). Створити папку в Google Drive, ID — частина адреси після `/folders/`. Поділитися з директором.
4. **Apps Script.** script.google.com → New project → назва «Резюме договору API» → вставити вміст `apps-script/Code.gs`.
5. **Властивості скрипта.** Project Settings (шестерня) → Script properties → Add:
   - `ANTHROPIC_API_KEY` = ключ з кроку 1
   - `CLIENT_ID` = `758495999284-fnsq0qf281d7vcd84hu7ri6eu2189psg.apps.googleusercontent.com`
   - `ALLOWED_EMAILS` = gmail директора (і інших, кому можна) через кому
   - `SPREADSHEET_ID` = ID таблиці з кроку 2
   - `DRIVE_FOLDER_ID` = ID папки з кроку 3 (якщо не потрібно зберігати скани — не додавати)
   - `SHEET_NAME` = назва аркуша (необов'язково, за замовчуванням «Реєстр»)
6. **Дозволи.** У редакторі вибрати функцію `authorize` → Run → дозволити доступ до Таблиць, Drive і зовнішніх запитів.
7. **Публікація.** Deploy → New deployment → тип Web app → Execute as: **Me**, Who has access: **Anyone** → Deploy → скопіювати Web app URL.
   (Доступ «Anyone» потрібен, щоб сайт міг звертатися до скрипта; захист — перевірка входу Google і список `ALLOWED_EMAILS`. Таблиця і папка доступні лише власнику скрипта і тим, з ким ними поділились.)
8. **Сайт.** В `index.html` вписати URL у `CONFIG.API_URL` → Commit. GitHub Pages оновиться за ~1 хвилину.

Після змін у `Code.gs`: Deploy → Manage deployments → Edit → Version: New version (URL лишається той самий).

## Доступ

Вхід через OAuth-клієнт «ESCORE Economics Form» (проєкт ESCORE-Maps), він у режимі Testing — заходити можуть лише тест-користувачі. Директора додати в Google Auth Platform → Audience → Test users (як у README smeta) і в `ALLOWED_EMAILS`. Якщо сайт на новому репозиторії має інший домен — домен `https://escoreodessa.github.io` уже дозволений, нічого міняти не треба.

## Налаштування

- `CONFIG.COMPANY` в `index.html` — як наша компанія називається в договорах. AI за ним визначає «нашу» сторону і рахує ризики саме для нас. Якщо в договорах повна юридична назва (ТОВ «…»), краще вписати її.
- Перелік полів таблиці — масив `SECTIONS` в `index.html`. Нове поле автоматично з'явиться і в запиті до AI, і новою колонкою в реєстрі.
- Модель — властивість скрипта `MODEL` (за замовчуванням `claude-sonnet-5-5`).

## Вартість і обмеження

Платний лише Claude API, оплата за обсяг. Скан читається як зображення, тому одна сторінка — орієнтовно 1,5–3 тис. токенів на вході. Договір на 10 сторінок — орієнтовно $0.10–0.20 на моделі Sonnet; точні цифри видно в логах Apps Script (Executions) після першого розбору. Актуальні ціни: https://platform.claude.com/docs/en/about-claude/pricing

- Файли — до 20 МБ разом, PDF — до 100 сторінок. Фото автоматично зменшуються до 2000 px.
- Фото з iPhone у форматі HEIC не підтримуються — зберегти як JPG або зробити PDF.
- Резюме — допомога, а не юридичний висновок. Суми, дати й номери пунктів звіряти з оригіналом.

## Файли

- `index.html` — весь сайт (без збірки; бібліотеки з CDN: html2pdf.js, Google Identity Services).
- `apps-script/Code.gs` — серверна частина для Apps Script: розбір через Claude API, збереження скану в Drive, запис у реєстр.
